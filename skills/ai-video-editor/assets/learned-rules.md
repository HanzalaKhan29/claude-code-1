# Learned rules (this editor's memory of the user's taste)

Read this file at the start of every project. These rules come from the user's own notes on past edits and
override general defaults in SKILL.md when they conflict (the user's taste wins; safety, truth and platform
specs do not change).

How to add a rule (only after the user agrees with "Should I add what we learned to the skill?"):

```
## <short rule name>  (added <YYYY-MM-DD>, project <name>)
Rule: <what to do or never do, specific and measurable>
Why: <the user's reason, in their words if possible>
Example: <timestamp + what was wrong + what fixed it>
Applies to: <all videos | Shorts | long-form | captions | graphics | sound>
```

Keep rules general enough to apply to the next video, not a fix for one frame. If a new note contradicts an
old rule, ask which one wins and update the old rule instead of stacking both.
